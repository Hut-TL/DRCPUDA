# A novel dual-representation consistent prototype-driven universal source-free domain adaptation method for fault diagnosis
This repository contains the implementation of the paper "A novel dual-representation consistent prototype-driven universal source-free domain adaptation method for fault diagnosis".
## Running the Code
- Download the datasets from the links below
- Place the dataset files in the DRCPUDA/datasets
- Run main.py
## Datasets
- HUST Dataset: https://github.com/CHAOZHAO-1/HUSTbearing-dataset
- PU Dataset: https://groups.uni-paderborn.de/kat/BearingDataCenter
